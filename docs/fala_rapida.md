# Falas curtas para decorar | 13 slides

1. **Capa:** “Nosso projeto é um sistema de gerenciamento de biblioteca feito em C++.”
2. **Problema:** “Queríamos guardar os livros sem usar banco de dados. Para isso usamos arquivos.”
3. **Funções:** “O sistema cumpre os cinco requisitos da atividade: cadastro, consulta, exportação, exclusão lógica e contagem.”
4. **Pastas:** “O código está em src. Os arquivos gerados ficam em data. Corrigimos o programa para localizar essa pasta.”
5. **Struct:** “Cada livro tem ID, título, autor, ano e status. O status determina se ele está ativo.”
6. **Fluxo:** “A função main mostra o menu, e o switch chama a função escolhida.”
7. **Cadastro:** “O sistema gera um ID e usa fwrite para salvar o livro no arquivo binário.”
8. **Consulta e contagem:** “A consulta procura um ID ativo. A contagem soma só registros com status igual a 1.”
9. **Exclusão:** “Excluir logicamente significa mudar status para 0, sem apagar o registro do arquivo.”
10. **TXT:** “O arquivo binário guarda os dados. O TXT é um relatório legível criado pela opção exportar.”
11. **Demonstração:** “Vou cadastrar, consultar, contar, exportar e excluir, para mostrar que tudo funciona.”
12. **GitHub:** “O projeto tem o código e instruções em um repositório público; cada integrante envia o link ao Classroom.”
13. **Conclusão:** “Aplicamos structs, funções e persistência de arquivos para atender aos requisitos. Obrigado!”
